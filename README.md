# Gridsmith Update & Asset Distribution Server 🌐

This repository serves as the public static distribution server for **Gridsmith**:
- update.json: In-app application update manifest.
- skins/catalog.json: Remote skin catalog and metadata index.
- skins/thumb/ & skins/full/: Optimized WebP skin artwork.

### Public Endpoints:
- **Base URL**: https://rehanpckhan-wq.github.io/gridsmith-updates/
- **Update Manifest**: https://rehanpckhan-wq.github.io/gridsmith-updates/update.json
- **Skin Catalog**: https://rehanpckhan-wq.github.io/gridsmith-updates/skins/catalog.json
- **Releases**: https://github.com/rehanpckhan-wq/gridsmith-updates/releases
